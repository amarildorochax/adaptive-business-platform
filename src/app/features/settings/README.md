# Feature: Settings

Ponto de extensão reservado para a UI de configurações da plataforma
(preferências de usuário, conta, workspace).

Diferente das demais features listadas, não existe ainda um módulo
correspondente em `@/core` (`src/core/` não possui `settings/`) — o
domínio de negócio de configurações, se necessário, será definido em
uma Sprint futura do Core antes desta feature ser implementada.

Intencionalmente vazio até a Sprint que definir e conectar esta
feature.
